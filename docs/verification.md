## 검증 범위

모바일 검증은 브라우저 내 해당 너비의 프레임에서 수행했으며 실물 기기 테스트는 아닙니다. 프레임 검증 탭에서는 출처 URL 없는 `MutationObserver.observe` 오류가 기록됐지만 메뉴 이동과 화면 표시는 정상 동작했습니다. 사이트 소스에는 MutationObserver 호출이 없고 일반 페이지 탭에서는 오류가 없었습니다. 인쇄 스타일과 상태 복구는 유지했으며, 긴 프로젝트가 여러 페이지로 나뉠 수 있도록 인쇄 규칙을 보완했습니다. 네이티브 인쇄 창에서의 PDF 저장·실물 출력은 검증하지 않았습니다. 이력서의 성능 수치나 스토어 배포 경험을 재측정/외부 검증한 것은 아닙니다.
