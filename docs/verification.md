# 포트폴리오 개편 검증 기록 (2026-10-29)

## PDF 저장 시 섹션별 페이지 나눔

- 인쇄 스타일에서 `main > section + section`에 `break-before: page`와 호환용 `page-break-before: always` 적용. 소개 다음의 경력·기술·학력 및 자격증·연락처는 각각 새 페이지에서 시작하도록 구성.
- 섹션 첫머리의 화면용 여백 제거. 중첩된 회사·프로젝트·상세 기여에는 강제 페이지 나눔을 적용하지 않으며, 긴 경력은 여러 페이지로 이어짐.
- 첫 페이지 앞이나 마지막 섹션 뒤에는 강제 나눔을 추가하지 않음. 회사·프로젝트 제목과 이어지는 본문이 분리되지 않도록 인쇄 규칙 보완.
- 기존 테스트 14개 및 빌드 통과. 화면 레이아웃과 콘텐츠는 변경하지 않음.
- Chrome 인쇄 창을 열어 확인하려 했으나 컴퓨터 제어 권한이 없어 실제 PDF 저장과 최종 페이지 수는 검증하지 못함. 별도 PDF 렌더러도 이 환경에 없어 PDF 파일은 생성하지 않음.

## 최근 콘텐츠 삭제에 따른 검증 오류 수정

- 사용자 커밋 `294419b`가 이커머스 프로젝트를 삭제한 뒤 `Validate portfolio` 실행 `40872850469`에서 `Unknown experience project: ecommerce`로 실패. GitHub Pages 배포 자체는 성공했지만, 생성 HTML이 갱신되지 않아 이전 내용이 게시된 상태였음.
- 삭제된 항목의 `profile.experience[].projectIds` 연결을 제거하고, 보존 테스트를 현재 4개 프로젝트·7개 상세 기여 기준으로 갱신.
- 이커머스/백오피스의 데이터 연결 및 화면 잔존 여부를 검사하는 회귀 테스트 추가.
- `npm test`: 14개 통과. `npm run build`: 성공. 생성된 `index.html`을 함께 커밋.
- 프로젝트 삭제 시 연결 데이터·보존 테스트·생성 HTML을 함께 갱신하는 절차를 README에 명시.

이하 내용은 직전 경력 중심 개편의 검증 기록입니다.

- 이력서 사진 원본 추출 및 화면 표시 확인. 원본 PDF는 게시하지 않음.

## 추가 화면 개편

- NOTES 섹션과 메뉴 제거. 기존 문서·뷰어·목록 데이터는 보존.
- `01 / EXPERIENCE`만 유지하고 별도의 프로젝트 목록·제목·필터 제거. 아이디알시스템 하위에 4개, We Bible 활동 하위에 1개의 상세 배치. 기존 프로젝트별 주소와 `#work` 앵커 유지.
- `profile.json`의 경력별 `id`와 `projectIds`로 소속·표시 순서 관리. 모든 프로젝트는 한 번씩만 표시되도록 검증.
- 회사 제목은 h3, 그 아래 수행 업무 제목은 h4로 구분. 스타일과 스크립트 파일 해시를 URL에 붙여 배포 시 캐시 갱신.
- `학력 및 자격증`으로 제목과 메뉴 이름 변경, 전체 섹션 번호 재정렬.
- 화면·모바일·인쇄 글자 크기를 기존 대비 15% 확대. 프로젝트 제목 18 → 20.7px, 요약 13 → 14.95px, 본문 12 → 13.8px.
- GitHub에 추가된 자기소개·경력 수정(`3da2199`)을 먼저 반영하고 보존. 항목 수에 맞춰 소개 배치가 자연스럽게 채워지도록 조정.

- `npm test`: 13개 통과.
- `npm run build`: 루트 `index.html`과 `dist/` 생성 성공.
- `node --check src/main.js`, `node --check src/render.js`: 통과.
- `git diff --check`: 통과.
- 8개 기존 기여 보존, 이력서상 소속·기간·자격, 5개 프로젝트 및 추가 업무 포함 여부 검사.
- 본문·메타데이터 변경 반영, HTML 이스케이프, 내부 앵커 및 보존된 학습 문서 경로 검사.
- 각 회사·활동 하위에 기존 내용이 모두 포함되는지, NOTES 제거 및 학력·자격증 제목 변경 검사.
- 자기소개에 포함된 `&` 문자를 HTML 이스케이프 후 비교하도록 기존 검증을 보완.
- 중복 프로젝트/상세 기여 ID, 잘못된 경력 연결, 잘못된 분류 및 실행 가능한 외부 URL 거부 검사.
- 경력에 연결하지 않은 프로젝트, 중복 배치 및 없는 프로젝트 연결을 거부. JSON 소속 변경만으로 표시 위치가 바뀌는지 확인.

## 브라우저 확인

- `/portfolio/` 하위 경로에서 페이지와 프로필 사진 표시, 가로 넘침 없음, 콘솔 오류·경고 없음.
- 별도의 ALL PROJECTS 및 필터가 없으며, 아이디알시스템 아래 4개·We Bible 활동 아래 1개로 표시되는지 확인.
- 핀앳 상세 펼치기 정상 동작. 기존 `#project-backoffice` 주소로 이동하면 이커머스 상세가 펼쳐지며 아이디알시스템에 포함됨.
- 이전 개편에서 확인한 기존 프로젝트 앵커는 자동 검사로 유지 여부 확인.
- 390px 및 320px 프레임의 가로 넘침 없음. 모바일 경력 메뉴 이동 및 경력→회사→상세의 시각적 계층 확인.

## 검증 범위

모바일 검증은 브라우저 내 해당 너비의 프레임에서 수행했으며 실물 기기 테스트는 아닙니다. 이전 개편의 프레임 검증 탭에서는 출처 URL 없는 `MutationObserver.observe` 오류가 기록됐지만 메뉴 이동과 화면 표시는 정상 동작했습니다. 사이트 소스에는 MutationObserver 호출이 없고 일반 페이지 탭에서는 오류가 없었습니다. 인쇄 스타일과 상태 복구는 유지했으며, 긴 프로젝트가 여러 페이지로 나뉠 수 있도록 인쇄 규칙을 보완했습니다. 네이티브 인쇄 창에서의 PDF 저장·실물 출력은 검증하지 않았습니다. 이력서의 성능 수치나 스토어 배포 경험을 재측정/외부 검증한 것은 아닙니다.
