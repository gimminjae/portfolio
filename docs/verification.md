# 이력서 반영 검증 기록 (2026-10-29)

- 사용자 제공 2026.09 이력서 2페이지의 텍스트와 렌더링 화면 확인.
- 아이디알시스템 재직 종료일, 프로젝트별 참여 기간, 회사/기타경험/교육 소속을 이력서와 대조.
- 서비스 프로젝트 5개 안에 기존 작업 8개를 상세 기여로 보존.
- We Bible·씨젠의료재단, 핀앳 추가 업무, 정보처리산업기사 및 교육 이력 추가.
- 이력서 사진 원본 추출 및 화면 표시 확인. 원본 PDF는 게시하지 않음.

## 자동 검사

- `npm test`: 11개 통과.
- `npm run build`: 루트 `index.html`과 `dist/` 생성 성공.
- `node --check src/main.js`, `node --check src/render.js`: 통과.
- `git diff --check`: 통과.
- 8개 기존 기여 보존, 이력서상 소속·기간·자격, 5개 프로젝트 및 추가 업무 포함 여부 검사.
- 본문·메타데이터 변경 반영, HTML 이스케이프, 내부 앵커 및 학습 문서 경로, 분류 개수 검사.
- 중복 프로젝트/상세 기여 ID, 잘못된 경력 연결, 잘못된 분류 및 실행 가능한 외부 URL 거부 검사.

- 이전 `#project-capa` 주소에서 라이프 체크 프로젝트의 해당 상세 기여로 이동 확인.

## 검증 범위

모바일 검증은 브라우저 내 해당 너비의 프레임에서 수행했으며 실물 기기 테스트는 아닙니다. 인쇄 스타일과 상태 복구는 유지했으며, 긴 프로젝트가 여러 페이지로 나뉠 수 있도록 인쇄 규칙을 보완했습니다. 네이티브 인쇄 창에서의 PDF 저장·실물 출력은 검증하지 않았습니다. 이력서의 성능 수치나 스토어 배포 경험을 재측정/외부 검증한 것은 아닙니다.
